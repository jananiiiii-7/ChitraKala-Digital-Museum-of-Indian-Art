## 🏛️ Project Overview
**ChitraKāla** (চিত্রকলা / चित्रकला) is a web application designed to map and showcase the geographic origins, materials, patrons, techniques, and historical evolution of Indian painting, sculpture, and folk craft.

From **8,000 BCE prehistoric rock art in Bhimbetka** to **20th-century modernism by Jamini Roy and the Progressive Artists' Group**, ChitraKāla provides an immersive 3-column interactive workspace with custom warm-terracotta dark maps, dynamic filtering, state indexing, and web speech audio guides.

---

## ✨ Key Features

- 🗺️ **Terracotta Dark Map Canvas**: Powered by Leaflet.js with custom dark sepia-terracotta tile filters, animated pulsing location markers, and custom popups.
- 🖼️ **21 Authentic Masterpiece Exhibits**: Comprehensive coverage across 14 states (Kerala, Madhya Pradesh, Tamil Nadu, Rajasthan, West Bengal, Maharashtra, Bihar, Odisha, Himachal Pradesh, Uttar Pradesh, Telangana, Andhra Pradesh, Gujarat, Karnataka).
- 📜 **On-Demand Quick Facts Dossier**: Click-to-inspect interface featuring high-resolution artwork, geographic coordinates, medium/pigment breakdowns, surface materials, patronage details, and spotlight fun facts.
- 🔊 **Web Speech Audio Guide**: Integrated browser SpeechSynthesis voice narrator for interactive visual and auditory learning.
- ⚡ **Multi-Dimensional Filters**:
  - **Art Form Practices**: Rock & Cave, Temple & Wall, Miniatures, Folk & Tribal, Modern Masters.
  - **Vertical Chrono-Rail**: Era step filters from Prehistoric (8000 BCE) to Modern Masters (1900+ CE).
  - **State Index**: Dropdown filtering by all 14 Indian states.
  - **Global Live Search**: Instantly filter by artist, medium, region, patron, or period.

## 🛠️ Tech Stack & Architecture

- **Frontend**: HTML5, Tailwind CSS, FontAwesome 6, Google Fonts (*Marcellus* & *Inter*).
- **Mapping Engine**: [Leaflet.js](https://leafletjs.com/) with OpenStreetMap tile layer and custom CSS filters.
- **Audio Synthesis**: Native Browser Web Speech API (`window.speechSynthesis`).
- **Deployment**: [Vercel](https://vercel.com/) static web platform.
